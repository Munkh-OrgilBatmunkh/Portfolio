# OrgilOS 95 — хувийн портфолио

React + Vite. Win95 хэв маягийн OS, цонх доторх агуулга нь модерн.

## Ажиллуулах

`npm install` → `npm run dev` → build: `npm run build`

## Өөрийн зураг, мэдээлэл

- Мэдээлэл: `src/data.js`
- Зураг: `public/images/me.jpg`, `public/images/schools/*.jpg`, `public/images/projects/ism-1.png` гэх мэт

## Бүтэц

`App.jsx` (OS: boot, desktop, Start, taskbar) · `components/Win.jsx` (цонх) · `apps/*` (модуль бүр тусдаа)
