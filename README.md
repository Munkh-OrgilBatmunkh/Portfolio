## Бүтээлч санаа

Портфолиогоо жирийн вэбсайт болгохын оронд **1995 оны Windows маягийн «үйлдлийн систем»** болгож хийлээ. Сайтад ороход OrgilOS 95 ачаалагдаж, ширээн дээр дүрсүүд, Start цэс, цонхнууд, taskbar-тай бодит ширээний орчин гарч ирнэ. Миний тухай мэдээлэл бүр нь нэг «апп» эсвэл «хавтас»:

| Дүрс            | Нээгдэх зүйл                                                 |
| --------------- | ------------------------------------------------------------ |
| Миний компьютер | Танилцуулга: зураг, нэр, чиглэл, нэг өгүүлбэр                |
| Миний тухай     | Боловсролын замнал: сургууль бүрийн зураг, он, анги          |
| Бүтээлүүд       | Төслүүдийн хавтас, төсөл бүр өөрийн «Project viewer» цонхтой |
| Ур чадвар       | Control Panel: бүх ур чадвар progress bar-тай                |
| Холбоо барих    | Dial-up холболт хийж байгаа мэт гарч, дараа нь имэйл, GitHub |
| MS-DOS          | Командаар төсөл, апп нээнэ                                   |

**Онцлох шийдлүүд**

- **Ширээний орчин:** цонх чирэх, томруулах, жижигсгэх, хаах, taskbar дээр шилжих. Цонх нь дэлгэцийн хэмжээнд өөрөө багтана.
- **Миний зураг:** 90-ээд оны dial-up интернет шиг пиксел байснаас аажмаар тодорч ачаална (`canvas`). Дарвал дахин ачаална.
- **Боловсрол:** сургууль бүр бүтэн дэлгэцийн зураг, хооронд нь аажим уусан шилжилт, зүүн талд цагийн мөр (rail).
- **Төслийн цонх:** зүүн талд мэдээлэл, баруун талд автоматаар эргэх зургийн carousel. Зураг дээр дарах, сум, thumbnail, swipe, томруулах, бүтэн дэлгэц.
- **Pixel-art дүрсүүд:** төсөл бүрийн дүрсийг текстэн «газрын зураг»-аас SVG-ээр өөрөө зурсан.
- **MS-DOS:** `playgrid`, `ism_museum`, `udp` гэх мэт нэр бичихэд төсөл шууд нээгдэнэ.

## Заавал байх 5 хэсэг хаана байна

1. **Танилцуулга** — «Миний компьютер» цонх
2. **Миний тухай** — «Миний тухай» (боловсрол) болон «Ур чадвар»
3. **Бүтээлүүд** — 4 төсөл: ISM Digital Museum, Playgrid, Stock App, UDP Pinger Server
4. **Холбоо барих** — «Холбоо барих» цонх
5. **Responsive ба байршуулалт** — гар утсан дээр цонх бүтэн дэлгэц болно, Vercel дээр байршуулсан

## Ашигласан технологи

- **React 18** + **Vite 5**, JavaScript (ES modules)
- **CSS** — бүгдийг өөрөө бичсэн (CSS framework, UI сан ашиглаагүй)
- **SVG, Canvas API** — pixel-art дүрс, зургийн ачаалах эффект
- Гадны сан: зөвхөн `react`, `react-dom`
- Wix, Tilda зэрэг бэлэн сайт бүтээгч, худалдаж авсан загвар **ашиглаагүй**

## Хавтасны бүтэц

```
src/
  App.jsx              OS: ачаалах дэлгэц, ширээ, Start цэс, taskbar, цонхны удирдлага
  data.js              Бүх агуулга (нэр, сургууль, ур чадвар, төслүүд) нэг дор
  styles.css           Бүх загвар
  components/
    Win.jsx            Win95 цонхны хүрээ (чирэх, томруулах, дэлгэцэнд багтах)
    PixelIcon.jsx      Pixel-art дүрс зурагч
    Mock.jsx           Зураггүй үед харагдах туршилтын дэлгэц
    RetroPhoto.jsx     Миний зургийн ачаалах эффект
    Logos.jsx          Имэйл, GitHub, LinkedIn логонууд
    Img.jsx            Ачаалагдаагүй зургийн placeholder
  apps/                Цонх бүрийн агуулга (модуль бүр тусдаа)
    About.jsx  Life.jsx  Skills.jsx  Projects.jsx  Contact.jsx  Retro.jsx (MS-DOS)
  assets/
    schools/           Сургуулийн зургууд
    projects/<id>/     Төслийн дэлгэцийн зургууд (1.png, 2.png ...)
public/images/me.jpg   Миний зураг
```

## Ажиллуулах

```bash
npm install
npm run dev        # хөгжүүлэлтийн горим
npm run build      # production build
npm run preview    # build-ийг турших
```

## Агуулга солих

- Бүх мэдээллийг `src/data.js` дотор засна (`ME`, `EDU`, `HARD`, `SOFT`, `LANG`, `PRJ`).
- Миний зураг: `public/images/me.jpg`
- Сургуулийн зураг: `src/assets/schools/` (нэр нь `data.js` дээрх `img`-тэй таарна)
- Төслийн дэлгэц: `src/assets/projects/<ism|pg|st|udp>/1.png, 2.png ...`
- Шинэ апп нэмэх: `App.jsx` дахь `REG` жагсаалтад нэг мөр нэмнэ.

## MS-DOS командууд

`help` · `dir` · `date` · `ver` · `whoami` · `cls` · `exit`
Төсөл нээх: `ism_museum`, `playgrid`, `stock_app`, `udp` (мөн `open <нэр>`)
Апп нээх: `about`, `life`, `skills`, `contact`, `projects`

## Байршуулалт

Репозиторийг GitHub-д push хийж, Vercel дээр **Import Project** хийхэд Vite-ийг автоматаар таньж байршуулна (Build: `npm run build`, Output: `dist`).
